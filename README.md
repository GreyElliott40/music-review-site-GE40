# music-review-site-GE40
A Letterboxd-style site for music. Search any album, rate it 1–5 stars, write a review, and track everything you’ve listened to. Built with HTML, CSS &amp; JavaScript on the MusicBrainz API, with Supabase accounts coming next. Also a learning project: I’m learning web dev from scratch with AI as a coding partner. Roadmap in CLAUDE.md.
